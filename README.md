# Weavers Paradise Combat Compatibility

Client-side compatibility add-on for Minecraft 1.21.1 and NeoForge. It keeps Weavers Paradise cosplay armor rendering correctly with Epic Fight, including mage armor from Iron's Spells 'n Spellbooks and EFM x Irons resource-pack models. It also supports using Epic Fight together with Better Lock On.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.199 or a compatible 21.1.x build
- [Weavers Paradise](https://modrinth.com/mod/weavers-paradise) 1.6.3+

## Optional integrations

- [Epic Fight](https://modrinth.com/mod/epic-fight)
- [Iron's Spells 'n Spellbooks](https://modrinth.com/mod/irons-spells-n-spellbooks)
- [Better Lock On](https://www.curseforge.com/minecraft/mc-mods/better-lock-on)

Epic Fight is optional. The add-on loads without it and applies its Epic Fight rendering fixes when Epic Fight is installed. Iron's Spells 'n Spellbooks and Better Lock On are also optional.

## Build

Run `gradlew.bat build`. The mod JAR is written to `build/libs`.
