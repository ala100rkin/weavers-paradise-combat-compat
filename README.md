# Weavers Paradise Epic Fight + Iron’s Spells Compatibility

Client-side NeoForge compatibility add-on for Minecraft 1.21.1. Keeps Weavers Paradise cosplay visible and correctly modeled with Epic Fight, including mage armor from Iron’s Spells ’n Spellbooks and EFM x Irons resource pack models.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.199 or compatible 21.1.x build
- [Weavers Paradise](https://modrinth.com/mod/weavers-paradise) 1.6.3+
- [Epic Fight](https://modrinth.com/mod/epic-fight) (required)
- [Iron’s Spells ’n Spellbooks](https://modrinth.com/mod/irons-spells-n-spellbooks) (optional)

Works with Weavers Paradise + Epic Fight, Weavers Paradise + Iron’s Spells ’n Spellbooks, or all three mods together.

## Build

Run `gradlew.bat build`. The mod JAR is written to `build/libs`.
