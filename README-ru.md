# Weavers Paradise: совместимость с Epic Fight

Самостоятельный клиентский аддон для NeoForge и Minecraft 1.21.1. Исправляет отображение косплея Weavers Paradise с модом Epic Fight.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.199 или совместимая версия 21.1.x
- [Weavers Paradise](https://modrinth.com/mod/weavers-paradise) 1.6.3+
- [Epic Fight](https://modrinth.com/mod/epic-fight)

## Сборка

Запустите `gradlew.bat build`. JAR-файл появится в `build/libs`.

Этот аддон независим от других аддонов совместимости Weavers Paradise.
