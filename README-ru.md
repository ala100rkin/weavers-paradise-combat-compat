# Weavers Paradise Epic Fight + Iron’s Spells Compatibility

Клиентский аддон совместимости для NeoForge и Minecraft 1.21.1. Исправляет отображение косплеев Weavers Paradise с Epic Fight, в том числе вместе с бронёй мага из Iron’s Spells ’n Spellbooks и моделями ресурспака EFM x Irons.

## Требования

- Minecraft 1.21.1
- NeoForge 21.1.199 или совместимая версия 21.1.x
- [Weavers Paradise](https://modrinth.com/mod/weavers-paradise) 1.6.3+
- [Epic Fight](https://modrinth.com/mod/epic-fight) (обязателен)
- [Iron’s Spells ’n Spellbooks](https://modrinth.com/mod/irons-spells-n-spellbooks) (необязателен)

Аддон работает с Weavers Paradise + Epic Fight, Weavers Paradise + Iron’s Spells ’n Spellbooks или со всеми тремя модами одновременно.

## Сборка

Запустите `gradlew.bat build`. JAR-файл появится в `build/libs`.
